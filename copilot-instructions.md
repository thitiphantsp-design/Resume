# Resume Web App — Copilot Instructions

Follow the **Karpathy Guidelines** (see SKILL.md) when working on this project.

## Key Principles

1. **Think Before Coding** — Always clarify requirements before implementing
2. **Simplicity First** — No over-engineering, no speculative features
3. **Surgical Changes** — Only edit what's necessary; don't "improve" unrelated code
4. **Goal-Driven Execution** — Define verifiable success criteria for each task

## Workflow

When asked to make changes:
- State assumptions explicitly
- Present multiple approaches if applicable
- Define success criteria before coding
- Make minimal, targeted changes
- Verify success before declaring done
